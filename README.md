# ladakh-hilux-game

 🚗 Ladakh Hilux 4x4 – 20 Mission Campaign
Game Development Project Report

📌 Project Overview
Ladakh Hilux 4x4 is a browser-based 3D-style off-road driving simulation game developed using HTML5 Canvas, CSS3, and JavaScript.
The game was created as a learning and development project, where AI tools were used for assistance in coding, design ideas, debugging, and optimization.
It features a mission-based system where players drive a Toyota Hilux through challenging terrains such as mud roads, asphalt, and landslide zones across 20 progressive levels.

🎮 Key Features
20-level mission campaign system
Pseudo-3D road rendering using Canvas projection
Terrain variety (mud, asphalt, landslide areas)
Vehicle control system (acceleration, braking, steering)
Obstacle system (rocks, trees, road hazards)
Mobile touch controls + keyboard support
Camera switching (third-person / first-person view)
Real-time HUD (speed, gear, mission progress)
Progressive difficulty system

🛠️ Technology & Tools Used
Core Technologies:
HTML5 (Canvas rendering engine)
CSS3 (UI and responsive design)
JavaScript (Game logic, physics, rendering)
AI & Development Tools:
ChatGPT (coding assistance, logic support, debugging)
Google Gemini (idea generation & optimization suggestions)
Blackbox AI (code assistance and reference support)
Testing / Development Platforms:
Replit (online coding & testing environment)
CodePen (UI testing and quick prototyping)

🎯 Controls
Desktop:
W – Accelerate
S – Brake / Reverse
A / D – Steering
Mobile:
Touch steering wheel – Direction control
Gas pedal – Accelerate
Brake pedal – Slow down
Extra controls: Camera switch, horn, and radio system

🧠 Highlights
Built using a custom pseudo-3D rendering system (no game engine)
AI-assisted development workflow
Real-time physics-based vehicle movement
Procedural-style terrain simulation
Mobile-first responsive design
Optimized and tested using online development platforms
